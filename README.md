# نت‌یار مهاجر

نسخه اولیه سرور و API برای نرم‌افزار مدیریت دفتر نت‌یار مهاجر.

## ساختار

- `Server`: پروژه ASP.NET Core Web API
- `Server/Data`: مدل‌ها و DbContext پایگاه داده
- `Database`: محل ایجاد خودکار فایل SQLite در زمان اجرا
- `Storage`: محل رزروشده برای فایل‌های پرونده در نسخه‌های بعدی
- `Backups`: محل رزروشده برای نسخه‌های پشتیبان

## پیش‌نیاز فعلی

- Windows 11 برای آزمایش فعلی
- .NET 10 SDK

> .NET 10 روی Windows 7 پشتیبانی نمی‌شود. برای پشتیبانی از Windows 7 باید نسخه جداگانه‌ای طراحی شود. Windows 10 نیز خارج از پشتیبانی عمومی مایکروسافت است.

## اجرا در ویندوز

از ریشه مخزن، CMD را باز کنید:

```cmd
cd /d مسیر\app\Server
dotnet restore
dotnet build
dotnet run --urls http://0.0.0.0:5080
```

سپس در CMD دیگری:

```cmd
curl http://127.0.0.1:5080/health
curl http://127.0.0.1:5080/api/services
```

## APIهای فعلی

| روش | مسیر | کاربرد |
|---|---|---|
| GET | `/health` | سلامت سرور و پایگاه داده |
| GET | `/api/database-check` | بررسی اتصال SQLite |
| GET | `/api/services` | فهرست خدمات فعال |
| POST | `/api/services` | افزودن خدمت |
| GET | `/api/subscribers` | جست‌وجوی مشترکان |
| POST | `/api/requests` | ثبت درخواست و تولید کد رهگیری |
| GET | `/api/requests` | فهرست پرونده‌ها |
| GET | `/api/tracking/{code}` | پیگیری با کد رهگیری |
| PATCH | `/api/requests/{id}/status` | تغییر وضعیت پرونده |

### نمونه ثبت درخواست آزمایشی

```cmd
curl -X POST http://127.0.0.1:5080/api/requests -H "Content-Type: application/json" -d "{\"fullName\":\"مشترک آزمایشی\",\"phone\":\"09123456789\",\"identityCode\":\"TEST123\",\"serviceId\":1,\"description\":\"آزمایش اولیه\"}"
```

### نمونه پیگیری

```cmd
curl http://127.0.0.1:5080/api/tracking/NY-XXXXXXXXXX
```

## وضعیت تکمیل

این مخزن در حال حاضر اسکلت سرور و APIهای پایه را نگه می‌دارد. رابط دسکتاپ، ورود امن، نقش‌ها و مجوزهای واقعی، مدیریت کارمندان، حضور و غیاب، حقوق و اضافه‌کاری، محاسبه پورسانت، حسابداری کامل، بارگذاری و دانلود امن فایل‌ها، گزارش‌ها، پشتیبان‌گیری زمان‌بندی‌شده و فایل نصب Setup.exe هنوز پیاده‌سازی و تست نشده‌اند.

## هشدار امنیتی مهم

این نسخه برای توسعه و آزمایش محلی است. APIها هنوز احراز هویت و مجوزدهی ندارند؛ بنابراین آن را در شبکه عمومی یا شبکه عملیاتی دفتر در دسترس قرار ندهید و اطلاعات واقعی مشترکان را وارد نکنید.

پیش از استفاده عملیاتی باید احراز هویت، کنترل دسترسی مبتنی بر نقش، اعتبارسنجی ورودی، محدودسازی شبکه، ثبت رویدادهای مدیریتی، پشتیبان‌گیری قابل‌بازیابی و EF Core Migrations پیاده‌سازی و آزمایش شوند.

پایگاه داده SQLite در مسیر `Database/netyar.db` نسبت به پوشه Server ایجاد می‌شود. این نسخه از `EnsureCreated()` استفاده می‌کند و برای تغییرات بعدی ساختار پایگاه داده باید به EF Core Migrations منتقل شود.
